    OPTIONNEL — "Net Send" moderne : notification push vers tous les téléphones
    Contexte
    Windows XP avait net send * (protocole NetBIOS) : un message s'imposait en popup modale sur toutes les machines du réseau.

    Désactivé depuis XP SP2 (2004) — spammeurs. Ne parle qu'aux machines Windows de toute façon.

    Équivalent moderne : SSE (Server-Sent Events) + overlay plein écran dans le navigateur. Même effet visuel, même réaction "imposée", mais sur les téléphones.
    Mécanique
    ── Serveur Flask ──
    GET /workshop/state
      → { "open": false }

    POST /workshop/open (dashboard)
      → flag in-memory = true

    ── Téléphones ──
    poll /workshop/state (1s)
    ou SSE /workshop/stream

    open == true →
      vibrate + son + overlay
      → redirect /champions
    Effets côté téléphone
    ✅ navigator.vibrate([200,100,200])
    Android Chrome — aucune permission requise

    ✅ Son d'alerte (/mp3/intro.mp3)
    Autorisé si l'utilisateur a déjà interagi

    ✅ Overlay plein écran animé
    "Le quiz commence !" — impossible à rater

    ❌ Notification OS (tiroir)
    Nécessite HTTPS + internet (Push API) — impossible en réseau local
    💡 Condition : la page /workshop doit être ouverte dans le navigateur. Si le téléphone est verrouillé → pas de vibration. En pratique les participants ont leur écran allumé pendant la session.
    Flow animateur → téléphones
    Dashboard ▶ POST /workshop/open ▶ flag = true (mémoire) ▶ poll ou SSE détecte ▶ 📳 vibrate + 🔊 son + overlay ▶ → /champions
