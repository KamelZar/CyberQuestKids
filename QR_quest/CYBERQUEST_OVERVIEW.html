PARCOURS PARTICIPANT — Du WiFi à la fin du workshop
1
Connexion WiFi
Le participant scanne le QR code WiFi.
L'OS détecte l'absence d'internet et ouvre automatiquement le captive portal.
AUTOMATIQUE
2
Captive Portal
Choix de la langue (FR/NL/EN).
Faux portail : Google / Apple / Facebook / Instagram.
Peu importe le bouton → Gotcha.
PHISHING PÉDAGOGIQUE
3
Page Gotcha
Affiche ce qui a été collecté : OS, navigateur, langue, IP, heure.
"Tu es au bon endroit... :-)"
RÉVÉLATION
4
Choix d'équipe
Carrousel de 10 personnages + option selfie.
Noms pris = grisés en live (poll 1s).
UUID généré + cookie posé.
1 APPAREIL / ÉQUIPE
5
Théorie + Démarrage
Page d'attente jusqu'au signal animateur.
Bouton "Ouvrir le workshop" → tout s'ouvre simultanément.
VERROU ANIMATEUR
6
Parcours libre
3 exercices à compléter dans la salle.
QR codes à scanner. Tracking en temps réel sur le dashboard.
JEU DE PISTE
7
Clôture
Page projetée devant le groupe.
Bilan réseau : temps connecté, pages vues, actions.
"Tu n'es pas invisible."

    ROUTES CLÉS
    GET / → captive portal
    GET /gotcha → page gotcha
    GET /team-select → choix équipe
    GET /teams/available → noms libres (poll)
    POST /teams/register → enregistrer équipe
    GET /workshop → page d'attente
    GET /cyberquest/id/exo/st → tracking pixel
    GET /dashboard → animateur live
    GET /dashboard/data → JSON events
    POST /dashboard/reset → reset session
    GET /closing → bilan final
    SÉCURITÉ
    UUID par appareil → cookie cq_uuid
    UUID inconnu → page neutre
    Reset = purge UUID + events + photos

    🎯 Montrer que se connecter à un WiFi inconnu expose des données personnelles (OS, navigateur, IP, langue)
    🎯 Illustrer le phishing de manière concrète et mémorable via le captive portal
    🎯 Démontrer en clôture que personne n'est invisible sur un réseau (inspiration Black Hat London)
    🎯 Encourager l'apprentissage par le jeu — coopération, amusement, démarche active
    🎯 Message final : "Tu as aussi un rôle à jouer dans la cybersécurité"
